Autonomous rover with vision and LiDAR

A two-wheel rover that follows a line and stops by itself when something is in its way. A laptop does the thinking and an ESP32 drives the motors.

  • ESP32 firmware that turns simple serial commands into motor speeds, with a 200 ms safety stop if commands stop arriving.
  • Smooth speed ramping and dead-zone handling, so even slow commands actually turn the wheels.
  • A ROS 2 bridge between the laptop and the ESP32, plus LiDAR-based obstacle stopping.
  • C++
  • ESP32
  • ROS 2 Jazzy
  • OpenCV
  • LiDAR
  • PlatformIO

GitHub alert platform

Connect a GitHub repository, set rules like "tell me when a new issue mentions bug", and get notified live in a dashboard.

  • A webhook endpoint that checks GitHub's signature (HMAC) before trusting any event.
  • A rule engine that matches event fields using equals, contains, greater than and less than.
  • Live notifications pushed to the browser with Socket.IO, behind JWT login.

Smart security camera alerts

Watches a camera feed, decides when something real is happening, and sends a Telegram alert with a short clip and a one-line description.

  • Cheap motion detection runs first; YOLOv8n only checks frames that moved, which keeps it fast on a laptop CPU.
  • Face recognition labels known people and flags unknown ones.
  • Saves a clip from just before to just after each event, and Gemini writes a caption and a daily summary.
  • Python
  • OpenCV
  • YOLOv8n
  • SQLite
  • Telegram Bot API
