Overview

Our UX case study of the food delivery app found several chances to improve the experience. We added a "Discover" section for unique local restaurants, simplified the checkout process and added personal recommendations. Together these changes made the app easier and more enjoyable to use.

We then designed a web version. It keeps the same experience across platforms while using different tools, which shows how the design system stays consistent.
